## 2026-10-24 冷却距离缩放勘误(用户指出)

- 用户指出:赛马娘实际冷却 = 基础冷却 × 距离/1000。核实:おんJウマ娘wiki「レース仕様」
  `[クールタイム]=[基礎クールタイム]×[距離]/1000 [s]`、ウマ娘スクール「スキル全般の基本」同式,
  与持续时间的距离缩放同规则。
- 修复前:引擎把基准值当实际值直接用(中山2500 弧线大师基准 30s 不缩放 → 100/875/1700m 三次发动,偏多)。
- 修复:`simulate` 中实际冷却 = cooldownSec × 距离/1000(数据侧仍存基准值,与 durationSec 同约定);
  测试断言改为精确 2 次(东京2400 实际 72s:160m 与 1760m 两弯道;漏乘系数会得 3 次,回归可被捕获)。
- 中山2500 复验:实际冷却 75s → 100m 与 1700m 两次发动(与游戏内长距离"约两次"体感一致)。
